<h1 align="center">IKUN</h1>


IKUN 是基于 Electron、Chromium 和 Playwright 的本地多环境浏览器。你可以为不同任务创建独立浏览器环境，分别保存登录状态、配置代理和浏览器参数，也可以通过本地 API 接入自动化脚本。

环境配置和浏览器会话均保存在本机，无需注册账号或连接厂商云端。

---

## 功能特点

- **独立浏览器环境**：每个环境使用独立数据目录，持久保存 Cookie、本地存储和缓存，支持多个环境同时运行。
- **环境管理**：自动递增数字命名、支持环境分组、搜索、跨页勾选、批量打开与批量删除。
- **代理管理**：支持 HTTP / SOCKS5 代理批量导入、连通性及出口 IP 检测，支持独立环境单独绑定代理。
- **原生一致策略**：CPU、内存、UA/Client Hints、Canvas、Audio 和 GPU 使用 Chromium 原生值，保证页面与 Worker 上下文一致。
- **内核管理**：内置 Chromium 内核下载与状态管理，启动时自动复用已下载内核。
- **本地自动化 API**：提供基于 Token 鉴权的本地 HTTP API，轻松对接外部自动化脚本。
