<h1 align="center">ikun</h1>


ikun 是基于 Electron、Chromium 和 Playwright 运行于 Windows 本地的多环境浏览器，可以为不同任务创建独立的浏览环境，分别保存登录状态、配置代理和浏览器参数，环境配置和浏览器会话均保存在本机，无需注册账号。

---

## 功能特点

- **独立环境**：每个环境使用独立数据目录，持久保存 Cookie、本地存储和缓存，支持多个环境同时运行。
- **环境管理**：自动递增数字命名、支持环境分组、搜索、跨页勾选、批量打开与批量删除。
- **代理管理**：支持 HTTP / SOCKS5 代理批量导入、连通性及出口 IP 检测，支持独立环境单独绑定代理。
- **原生策略**：CPU、内存、UA/Client Hints、Canvas、Audio 和 GPU 使用 Chromium 原生值与 Worker一致。
- **内核管理**：内置 Chromium 内核下载与状态管理，启动时自动复用已下载内核。

---

## 快速开始

1. **准备内核**：进入「系统设置」先下载 Chromium内核；已检测到自动跳过。
2. **添加代理**：进入「代理管理」添加代理并检测连通性，格式保存每行一个。
3. **新建环境**：进入「新建环境」按照语言以及添加的代理创建独立的浏览环境。
4. **环境管理**：进入「环境管理」可以打开所添加的环境以及编辑/删除环境。
